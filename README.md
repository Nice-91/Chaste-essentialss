# Chaste Essentials - E-Commerce Platform

A full-stack e-commerce platform for selling products online with shopping cart, admin dashboard, and WhatsApp integration.

##  Live Demo
[https://chaste-essentialss.vercel.app/](https://chaste-essentialss.vercel.app/)

## Features
- Product catalog with category filtering
- Shopping cart functionality
- Admin dashboard for product management
- WhatsApp Business API for making orders
- JWT authentication
- Responsive mobile-first design

## Technologies
- Frontend: React, CSS
- Backend:Django, Django REST Framework
- Database: PostgreSQL
- Deployment: Vercel

## Setup

### Backend
```bash
git clone https://github.com/Nice-91/chaste-essentials.git
cd chaste-essentials
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend
```bash
git clone https://github.com/Nice-91/Chaste-essentialss.git
cd Chaste-essentialss
npm install
npm start
```
